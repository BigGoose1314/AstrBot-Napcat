AstrBot 网易云点歌插件，纯 Python 直连官方 API，零外部服务依赖。
点歌后下载音频到本地，以 QQ 语音消息发送 —— 同一首歌 30 分钟内重复点播自动命中缓存秒发。
支持 VIP Cookie 点播完整版、AI 自然语言点歌、音乐卡片降级链。
二次创作（Fork & Enhanced）：本仓库基于 xiaoyunsha/astrbot_plugin_netease_music 二次开发，在原插件基础上新增了语音消息下载发送、缓存复用等功能，感谢原作者的开源贡献。
